# 면접 준비

[공통 규칙](references/workflow.md)과 [면접 규칙](references/interview-workflow.md)을 적용한다.
사용자의 명시적 요청이 이 스킬의 기본 진행 방식보다 우선한다.

1. 현재 선택된 JD·이력서·경력 자료를 재사용한다. 자료가 없으면 목표 직무와 연습할 경험을
   물어 일반 연습으로 시작한다. 프로젝트·JSON·앱·계정 연결을 요구하지 않는다.
2. JD의 요구사항을 실제로 제공된 경력과 연결하고, 근거 있음/부분 있음/확인 필요를 구분한다.
   관련 경험이 없으면 공백으로 남긴다. 사용 금지 자료는 질문·답변 예시에서도 제외한다.
3. 핵심 질문 3~5개와 각 질문의 목적·선택 자료 참조·확인할 공백을 제안한다.
   답변 개요는 상황/과제/본인 행동/결과/한계로 구성하되 숫자·역할·결과를 만들어 채우지 않는다.
   팀 결과와 개인 기여를 구분한다. 일반 연습은 근거 확인을 마친 면접이라고 표시하지 않는다.
4. 코칭(답변마다 피드백)과 실전 연습(마지막에 종합 피드백)을 안내하고 사용자가 선택하면
   `mock-interview`로 이어간다. 선택이 없으면 코칭을 기본으로 하며 첫 질문은 한 개만 한다.

음성은 가능한 환경에서 사용자가 ChatGPT 기본 음성을 켜는 선택 사항이다.
도구/무료 계정 한도를 우회하거나 별도 API·앱 설치로 전환하지 않는다.
저장 요청 시 [세션 형식](references/schemas/interview-session-1.0.schema.json)과
[검사·읽기용 요약 도구](references/interview.py)를 사용한다. 저장 없이 대화로도 진행한다.
